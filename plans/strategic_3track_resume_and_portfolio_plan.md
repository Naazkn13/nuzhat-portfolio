## 1. Executive Summary & Strategic Direction Audit

### Is Pursuing 3 Separate Tracks the Right Direction?
**Yes, in strategy — but only if executed with a Staged Sequence rather than simultaneous dilution.**

#### The Reality of the Job Market in India (1–2 Years Experience)
1. **The Keyword Match Reality:**
   * Enterprise MNCs and Banks (JPMorgan, Morgan Stanley, Barclays, Nomura, Capgemini, LTI Mindtree) search specifically for `Java`, `Spring Boot`, `Microservices`, `Hibernate/JPA`, and `JUnit`.
   * FinTechs, High-Growth Startups (Zerodha, Groww, Razorpay, AngelOne, Swiggy) search specifically for `Python`, `FastAPI`, `PostgreSQL`, `Distributed Systems`, and `Docker`.
   * AI-First Startups and Modern Product Labs search specifically for `RAG`, `Vector Databases`, `Embeddings`, `LLM Integration`, and `Python`.
   * Sending a single "generalist" resume that mentions everything equally causes ATS algorithms to rank you in the middle (50–60% match score) for all three, resulting in zero callbacks. Tailoring 3 distinct resumes is mathematically and strategically the right move.

#### The Big Risk to Avoid (The "Split Personality" Pitfall)
* If you try to prepare for Java Spring Boot system design, Python concurrency, and AI transformer math all in the same week, you will suffer from cognitive overload and interview fatigue.
* **The Critical Gap Today:** You have battle-tested production proof in **Python/RegTech** and functional projects in **AI/ML**, but your Java experience is currently backed by a certification (DVOC Institute) without an enterprise-grade Spring Boot project on GitHub.
* If you apply to high-paying Java roles today, you may get filtered at the technical coding / Spring Boot L1 round.

## 3. The Blueprint for the Java Spring Boot Project

To avoid building a generic, ignored project (e.g., Bookstore, Todo List), build a project that **amplifies your existing RegTech/BFSI background**:

### Project Concept: `TradeSentry — RegTech Pre-Clearance & Audit Microservice`
* **Why this works:** It mirrors the logic you already understand from Novus Comply, but implemented in standard Enterprise Java! Interviewers will see instant continuity between your company experience and your Java skills.
* **Key Architecture:**
  * **Framework:** Java 21, Spring Boot 3.3+
  * **Data Layer:** Spring Data JPA with PostgreSQL, Hibernate, Flyway migrations
  * **Security:** Spring Security with JWT authentication and granular Role-Based Access Control (`ROLE_TRADER`, `ROLE_COMPLIANCE_OFFICER`, `ROLE_ADMIN`)
  * **Business Logic:**
    * Pre-clearance trade request submission.
    * Automated checking against a restricted ticker / UPSI grey-list.
    * Maker-checker approval state machine.
  * **Caching & Performance:** Redis for caching restricted security lists (reducing DB hits by 90%).
  * **Testing:** JUnit 5 and Mockito for unit testing controllers and service layers.
  * **Containerization:** Multi-stage Dockerfile and Docker Compose setup.
* **Development Timeframe:** 5–7 days focused build.
